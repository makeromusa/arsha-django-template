Case Study: PesaSmart App

Project Information

  • Category: Mobile App & Fintech
  • Client: PesaSmart Kenya Ltd
  • Project Date: August 2026
  • Tech Stack: Django REST, Flutter, PostgreSQL

Automating Personal Budgeting for Kenyan Users

PesaSmart hired Fahari Digital to build a mobile budgeting application. The app reads transaction SMS notifications, organizes daily spending into categories, and summarizes monthly expenses for Kenyan smartphone users.

The application was built with Flutter on the frontend and Django REST framework on the backend, using PostgreSQL for database storage and secure token authentication.
